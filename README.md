# TableSync

AIマッチング晩ごはんのSaaSプロトタイプです。

## 起動

`index.html` をブラウザで開くと動きます。依存パッケージはありません。

## 入っている機能

- 参加者の登録、削除、ローカル保存
- 興味タグ、目的、予算、食事条件を使ったグループ生成
- 店舗候補の自動割当
- 当日案内文の生成
- JSON / CSV エクスポート

## 次に足すもの

- 認証と参加者用フォーム
- 事前決済
- 店舗在庫と予約API連携
- 本人確認、通報、ブロックなどの安全機能
- マッチング結果のA/Bテスト
